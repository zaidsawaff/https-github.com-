# Third-party data and redistribution boundary

This bundle reports aggregate audit and performance results derived from three public datasets. It does not include or sublicense the underlying images, masks, annotations, or provider metadata.

| Dataset | Provider license reported by the source | Redistribution in this repository |
|---|---|---|
| Nail Segmentation Dataset | CC0 Public Domain | No |
| Nail Disease Detection Dataset | CC BY-NC-SA 4.0 | No |
| HP Nail Images for Early Disease Detection | Apache 2.0 | No |

Users must download source files from the URLs in `data/source_dataset_registry.csv`, verify the current provider terms, and cite the original dataset creators. This repository's licenses apply only to study-generated code, documentation, and aggregate tables to the extent those materials are independently licensable.
